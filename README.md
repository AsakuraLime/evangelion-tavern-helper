# EVANGELION Tavern Helper scripts

External scripts for the EVANGELION 4.3 SillyTavern character card.

- `mvu-schema.js`: MVU/Zod variable schema.
- `worldbook-controller.js`: timeline world-book switch and shared initialization API.
- `event-engine.js`: timeline-to-variable event bridge.
- `status-panel.js`: MAGI observation terminal linked to MVU state.

The card imports these files through jsDelivr. Display transforms remain embedded in the card.
